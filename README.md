# scripts

Some scripts I've made.

- lwpe-helper: interactive cli for [linux-wallpaperengine](https://github.com/Almamu/linux-wallpaperengine)
- sync_leds_with_accent: syncs KDE accent color with my keyboard backlights (ASUS, Logitech)

These scripts are heavily catered towards my system so you'll definitely need
to change a few things (e.g., variables) to be able to reuse it on your setup.
